# Next-Busses
## (Still under construction) webapp for finding the next arrival time of a *CT Transit* bus at any official stop

### - Please note that *this is not a trip-planning app!* This app is meant to provide simple, up-to-date information on when the next bus will be arriving to pick you up from your stop.

### Current Features:
- (main branch) (Soon to be deprecated) Tkinter interface, Google-Maps API behind the scenes, use requires personal Google-Maps-Routes API key and creation of a local list of bus-stop information

### Planned upcoming Features:
- Move from using Google APi to using GTFS data from *CT Transit* directly
- Web interface for users to find their routes+stops
- Ability to pin next-bus info about selected stops to the top of the page for the duration of the session

#### This webapp uses external APIs/GTFS feeds to provide its services, but will never track/store any user data itself.
